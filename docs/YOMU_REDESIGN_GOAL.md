# Yomu 阅读器与首页/书库视觉重构 — 无框、单页、出版物体验

## 用户最终要求

当前 Yomu UI 难看，问题不是缺少装饰，而是线条、框框、卡片和分栏太多。
必须重新设计视觉层，但保留现有全部功能。整体要像一款精致的电子书/阅读 App，
而不是后台管理页面。

特别要求：**小说阅读页是一页连续内容**，不要左右分页、左右箭头、横向滚动或左右
双栏。正文默认从上往下连续滚动。

## 一、全局设计方向

视觉关键词：安静、纸张、编辑部、留白、低干扰、精致。

禁止：
- 大量可见边框
- 黑色粗线和黑色标签块
- 每个内容都包成卡片
- 3D 阴影、厚重描边
- 阅读页左右分页/左右箭头/横向滚动
- 为了“功能齐全”堆很多常驻文字按钮

统一：
- 共享 CSS 变量、字体系统、主题色
- 线条只用于极少数必要分隔，透明度低
- 主要靠字号、留白、颜色层级表达结构
- SVG 图标，不使用 emoji
- 手机和桌面共享设计语言，但布局不同：手机单列，桌面充分利用横向空间

主题：
- 纸张：背景 #F7F3EA，正文 #282521，次级 #8D867C，低饱和茶色强调
- 深夜：背景 #141414，正文 #D8D2C8，次级 #858078，暗金/灰蓝强调
- 原有四档护眼色保留，但统一为无框纸张主题

## 二、阅读器（最高优先级）

### 必须移除
- `vertical-reading` 默认阅读路径和设置入口（不要在默认阅读器中横向阅读）
- #novel-content 横向滚动容器
- scrollLeft 阅读进度逻辑
- 左右翻页/箭头/左右边缘翻页操作
- 任何“左页/右页”视觉结构

### 必须实现
- 正常纵向 document scroll，全文是一页连续内容
- 阅读进度基于 scrollTop/scrollHeight
- 段落从上到下自然流动
- 保留屏幕中央点按呼出控制栏、沉浸模式、字体/字号/行距/背景设置、进度、目录、
  搜索、生词标注/翻译等现有功能
- 书签、阅读位置、离线阅读、字体分流不能回归

### 阅读页视觉
- 正文最大宽度 680-720px，桌面居中；手机左右 22-26px
- 正文 20-22px，行高 2.0-2.15
- 段落之间使用留白，不用卡片/边框
- 日文正文保持明朝体，假名字体系统继续工作
- 首行缩进 1em（按现有内容结构适配）
- 章节标题使用大号明朝体，不加左侧粗黑线，不加黑色标签块
- 书名/作者轻量呈现
- 前言/作者信息改成自然的文字排版，不要网格表格线

### 阅读控制栏
- 默认隐藏；点击屏幕中央显示
- 顶部轻量浮层：返回、书名、设置（图标优先）
- 底部只保留一条细进度线/轻量进度文字
- 半透明、低对比、短暂自动消失
- 不遮挡正文、不常驻大面积 chrome

## 三、首页“最近/精选书籍列表”

保留现有功能：搜索、打开、下载、最近阅读、进度、长按菜单、下拉刷新、离线状态、
新着标识、语言/筛选入口。

重新设计：
- 不要密集边框卡片墙
- 顶部采用大标题+一句轻量说明+胶囊搜索框
- 最近阅读采用横向“继续阅读”区域：封面/标题/进度，简洁无框
- 书籍列表采用编辑部式纵向列表：小封面 + 标题/作者/短信息 + 轻量进度线
- 桌面 1280/1920：左侧主内容宽列+右侧“最近阅读/筛选/统计”侧栏，或多列但保持
  空气感；不要把手机单列拉宽
- 手机 390：单列，触控目标≥44px，封面比例稳定，信息不拥挤
- 空状态使用大留白+单个线性图标+短文案，不用空状态卡片
- 书卡点击打开；显式更多按钮打开下载/删除/标记/分享等现有菜单
- 书卡不要使用行级左右滑动，避免与页面手势冲突

## 四、“书库/书籍列表”页面

保留现有功能：青空文库目录、搜索、分类/作者筛选、排序、下载、已下载标记、分页/
懒加载、错误重试、离线缓存。

重新设计：
- 页面标题“书库”，下方显示数量/当前筛选状态的轻量文字
- 搜索为单一高质量入口；筛选用图标按钮+弹出面板，不要常驻一排框
- 桌面：搜索/筛选工具栏 + 宽内容区，书籍采用 2-3 列通透网格或列表切换；侧栏可
  显示分类/作者索引
- 手机：默认纵向列表，必要时两列小封面网格；不强迫桌面网格缩成卡片
- 列表/网格切换保留但用图标按钮表达
- 书籍封面、标题、作者、日文原名和下载状态层级清楚
- 已下载状态用细色点/小图标，不使用巨大 badge
- 加载骨架使用低对比 shimmer，不要一堆带边框方框
- 结果为空：图标+“没有找到匹配作品”+清除筛选文字操作

## 五、功能不回归清单

逐项验证：
- 首页搜索/打开/下载/最近阅读/进度/长按菜单/下拉刷新
- 书库搜索/分类/作者/排序/懒加载/离线缓存/下载
- 阅读器纵向滚动、阅读位置、进度、章节标题、目录
- 字体预设、汉字/假名分流、字号、行距、四档背景、亮度
- 沉浸模式、点屏控制栏、搜索、翻译/词卡、生词标注
- PWA 离线打开和 service worker
- Android WebView 不出现横向滚动或左右分页

## 六、验收

390x844、768x1024、1280x800、1920x1080 四视口：
- 首页、书库、阅读页各截图
- 阅读页确认 `scrollWidth === clientWidth`，无横向滚动
- 不存在左右翻页按钮/左右页面容器/vertical-reading 默认入口
- console 零错误
- 亮/暗主题各一组
- 桌面利用横向空间但不把手机布局拉宽
- `git diff --check`、静态 JS 检查、PWA 离线回归
- 最终提交并 push，报告写入 `docs/yomu-redesign/REPORT.md`
