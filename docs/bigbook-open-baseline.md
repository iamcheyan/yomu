# 大书打开基线（§五验收纪律）— 2026-08-14

> 目标条款：任何大书打开须测 parse、首屏和滚动，不得以"服务返回 200"代替体验验收。

## 测量对象

仓库内最大作品 JSON：`data/novels/2012_ruby_7800.json`（《道標》宮本百合子）
- 文件 2.72MB（HTTP 传输体 1.02MB，压缩生效）
- 9,769 段、无章节结构（flat paragraphs）

## 实测（Chrome headless 390×844，本地 :8830）

| 阶段 | 耗时/结果 |
|---|---|
| fetch（含解压） | 87 ms |
| `JSON.parse` | 3 ms |
| 书库搜索→下载→打开（含渲染首屏 chunk） | 189 ms，reader-view.active ✓，hash/标题一致 ✓ |
| 首屏 DOM | 50 段（渐进渲染，非一次性 9.7k）✓ |
| 连续滚动 | 触底增量渲染正常，进度更新 ✓ |
| 深位置重载恢复 | 需渲染至已存 paraIndex（极端 100% 时全量 9,769 段），无错无崩溃，约 4.5s 安定 |
| console | 0 错误 |

## 结论与边界

- parse/首屏/滚动全部达标，无阻塞主线程的异常热点。
- 已知边界（预存行为，非本次回归）：进度恢复按需渲染到已存段落，
  若用户读到全书末尾，下次打开会一次性渲染全部段落。9.7k 段在
  headless 桌面 ~4.5s 安定；低功耗墨水屏真机未测（Android 真机回归
  仍是遗留项）。若真机出现卡顿，缓解方向是恢复渲染设上限 +
  视口外懒渲染——属后续优化，当前不动。
